# university-students-clearance-automation
The University Students Clearance Automation System is a desktop application developed using Java and JavaFX to automate the traditional university clearance process.

The system allows students to request clearance and enables university departments to review, approve, or reject requests digitally. It helps reduce manual paperwork, minimizes delays, and ensures a more transparent and efficient clearance workflow.

Key Features:

Student clearance request submission

Department approval and verification

Real-time clearance status tracking

User-friendly JavaFX graphical interface

Organized and automated clearance workflow

This project demonstrates the use of JavaFX for GUI development and Java-based system design for managing academic administrative processes.
